# Server Configuration

The app connects to an ArcGIS Server for map data and an optional custom backend API for authentication and map metadata.

## ArcGIS Server

| Setting | Default | Configurable |
|---------|---------|--------------|
| IP | `192.168.105.219` | Yes (Settings screen) |
| Port | `6080` | Yes (Settings screen) |
| Protocol | `http` | Yes (Settings screen, HTTP/HTTPS) |

Configured in `src/hooks/useServerConfig.ts` and persisted in `expo-secure-store` under the key `serverConfig`.

### Map loading modes

| Mode | Source | Server URL |
|------|--------|------------|
| **Static** (default) | `src/assets/mobile4.html` | Hardcoded to `http://192.168.105.219:6080` |
| **Dynamic** | Generated by `src/assets/mapTemplate.ts` | From secure store settings |

Toggle between modes in the Settings screen via the "Pagina dinamica" switch.

## Custom Backend API

| Setting | Value |
|---------|-------|
| Host | `172.16.65.33` (hardcoded in `src/services/api.ts`) |
| Port | `8000` |
| Protocol | `http` |
| Base URL | `http://172.16.65.33:8000/api/v1` |

This backend provides:
- Guest token authentication (`POST /auth/guest-token`)
- Public map HTML content (`GET /map/public-map/{slug}`)

## Settings screen

The Settings screen (`app/settings.tsx`) exposes:

| Section | Field | Type |
|---------|-------|------|
| Apariencia | Modo oscuro | Switch (dark/light theme) |
| Configuracion del servidor | Pagina dinamica | Switch (static/dynamic mode) |
| | Protocolo | HTTP / HTTPS |
| | IP del servidor | Text input |
| | Puerto | Text input |

Settings are saved to `expo-secure-store` and the map WebView is reloaded when the user returns to the map screen.

## Network security

- iOS: `NSAllowsArbitraryLoads: true` (allows HTTP connections)
- Android: `usesCleartextTraffic: true`
- Configured in `app.json` via `expo-build-properties`
